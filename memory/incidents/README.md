# Incidents

One note per live problem, written by the Fix session that handled it (ADR 0022). File name: YYYY-MM-DD-short-name.md. No visitor names, emails or transcripts: describe what happened, not who.

The test is required: every incident becomes a test so it cannot come back silently. The lesson also goes to memory/procedural/lessons.md.

```
# Incident YYYY-MM-DD: <what visitors or founders saw>

- When found, by whom:
- Cause:
- Fix: (commit or pull request)
- Test added: (file and check name)
- Lesson:
- Still open:
```
