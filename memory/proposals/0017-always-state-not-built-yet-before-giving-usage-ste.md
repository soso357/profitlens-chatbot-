## Why
Ioseb was confused and frustrated ('why are us kidding me?') after being given Render setup steps for the off switch before realizing it wasn't built, thinking it might already affect the live chatbot.

## What
Add a rule to workflow.md/CLAUDE.md: when describing a feature not yet built, lead with an explicit 'this doesn't exist yet' before any step-by-step instructions.
