# Improvement proposals

The self improvement queue (docs/workflow.md, "Capability evolution"). One file per proposal: NNNN-slug.md.

Lifecycle, recorded in the `status:` line:

proposed -> approved -> built   (or rejected, or deferred)

- **proposed**: written by the session summarizer or by Claude (skill: propose-capability). Nothing is built.
- **approved**: Ioseb said yes. Claude builds it in a later session (skill-creator for skills), with evals where it makes sense.
- **built**: the file's "Decision" section names what was created and where.
- **rejected / deferred**: the reason is written down so the same idea is not proposed again.

Open proposals show in the statusline ("N proposals to review") and in the session start brief.
