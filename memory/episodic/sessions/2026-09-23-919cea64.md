## Decisions
- Session summaries stored as Markdown files plus a SQLite search index. Chosen by Ioseb (picked the recommended option).
- Summary generation is fully automatic on session end. Chosen by Ioseb.
- Split CLAUDE.md immediately rather than wait for the other terminal to finish. Chosen by Ioseb.
- Install the official Anthropic plugin set (4 plugins) rather than third-party alternatives. Chosen by Ioseb.
- Obsidian shows live links to real project files, not copies, and includes everything readable except secrets and visitor data. Chosen by Ioseb.
- Commit by staging files by name rather than blanket `git add`. Chosen by Claude, applied consistently after the other terminal's blanket-commit habit caused friction.
- Telegram integration is alerts-only; email stays the system of record; a Telegram failure must never block the email or the visitor's reply (recorded in ADR 0014, originally decided in the other terminal).

## Problems and lessons
- A scripted text replacement in the phase-gate skill silently did nothing (grep found no match); caught by checking rather than assuming the script worked, and fixed by hand.
- The first version of the summarizer's skip rule would have skipped summarizing any session with only one long user message; only caught by dry-running it on this session's real transcript before trusting it.
- Draft docs used "he" for Ioseb even though pronouns were never stated, requiring a sweep and rewrite to neutral wording.
- Two Claude Code terminals working on the same repo diverge because CLAUDE.md is only read once at session start; the second terminal kept following the old (pre-split) rules, writing decisions into CLAUDE.md and committing everything at once.
- Obsidian only draws graph connections from `[[wikilinks]]`, not plain file paths, so project docs that reference each other by path showed up disconnected until a generated map file linked them all from one index note.
