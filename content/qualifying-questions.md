# Qualifying questions

DRAFT for founders to edit. When a visitor wants the call or the analysis, the agent asks these one at a time, in this order, in its own friendly wording close to what is written here. It skips any question the visitor has already answered earlier in the chat.

1. What is your first name?
2. What is the name of your restaurant?
3. Which state is it in? (This tells the agent which time zone to use for booking. Ask only for the state, not the city.)
4. What is the best email to reach you?

Then the agent shows up to three free call times as buttons.

The agent asks nothing else: no questions about the type of restaurant, number of locations, who sets prices, menu size, or which option the visitor wants. Every visitor who gives these four details can book; the founders judge fit on the call. (Ioseb, 2026-09-28)
