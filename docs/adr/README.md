# Architecture Decision Records

One file per decision: NNNN-short-title.md, using template.md. Numbers never change and are never reused.
Status is one of: Proposed, Accepted, Superseded by NNNN, Rejected.
A decision is never edited after it is Accepted. To change it, write a new ADR that supersedes it and update the old one's Status line only.
Founder decisions (0001 to 0006) are reopened only with a founder.
Skill: new-adr.
