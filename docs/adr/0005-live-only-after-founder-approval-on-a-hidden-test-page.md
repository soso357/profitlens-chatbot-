# ADR 0005: Live only after founder approval on a hidden test page

- Status: Accepted
- Date: 2026-09 (founder brief)
- Decided by: Founders

## Context

A public mistake is costly; founders must see the real thing first.

## Decision

The widget runs on the Render URL and a hidden test page until founders approve it for the homepage.

## Consequences

Phase 4 must deliver a hidden test page approach.
